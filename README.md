# Grim Client - Fabric 1.21.11

A Minecraft client mod with a ClickGUI and legit features.

## Features

### Visual
- Fullbright - Increase gamma/brightness
- Zoom - Zoom in/out view
- Free Look - Separate camera from player rotation
- Trajectories - See projectile paths
- HitFX - Visual hit effects
- Tint Damage - Screen tint on damage
- Crystal Chams - Highlight end crystals
- No Render - Hide unwanted particles
- Particle ESP - Highlight important particles

### Movement
- Sprint - Auto sprint when moving forward
- Gui Move - Move while GUI is open
- No Push - Reduce knockback
- Elytra Control - Better elytra flight
- Legit Strafe - Smooth strafing

### Utility
- Free Cam - Spectator-like camera
- Auto Sign - Auto sign with text
- Auto Shear - Auto shear entities
- Tps Sync - Sync with server TPS
- HUD - Display mod info

## Building

### Option 1: Local Build (requires JDK 21)
```bash
chmod +x gradlew
./gradlew build
```
The jar will be in `build/libs/`

### Option 2: GitHub Build (on phone, no PC needed)
1. Create a free GitHub account at github.com
2. Click "Fork" on this repository (or create new repo with this code)
3. Push the code to your GitHub repository
4. Go to "Actions" tab
5. The build will run automatically
6. Download the .jar from the artifacts

## Installation
1. Install Fabric Loader 0.19.5+ for Minecraft 1.21.11
2. Put the .jar in your mods folder
3. Launch Minecraft

## Usage
- Press RIGHT SHIFT to open the GUI
- Click categories to expand/collapse
- Click modules to toggle them on/off
- Use the search bar to filter modules

## Keybinds
- RIGHT SHIFT - Open/close GUI
- ESC - Close GUI

## Notes
- This mod is client-side only
- Some modules may not work on all servers
- Always check server rules before using
